# Clear writing skill

Use the clear-writing skill to make prose easier to understand while preserving
its meaning, terminology, tone, and uncertainty.

The skill covers how to name the main actor, express actions as verbs, keep
subjects and verbs close together, and connect familiar information to new
information. It includes guidance on when to keep passive voice and abstract
nouns.

## Files

- [SKILL.md](SKILL.md) contains the instructions and editing workflow.
- [Sentence clarity reference](references/sentence-clarity.md) contains examples,
  diagnostic questions, and exceptions.

## How to use it

Clone the repository:

```sh
git clone https://github.com/wanderingspirit03/clear-writing-skill.git
```

Give your agent `SKILL.md` as instructions, and keep the `references` directory
beside it so the agent can read the examples. Ask the agent to draft, rewrite,
review, or explain a passage.
